SCIENCE BUILD LAB — STARTER WEBSITE
====================================

FILES
- index.html: the whole website (HTML, CSS, and JavaScript in one file).

TEST IT ON YOUR WINDOWS PC
1. Extract the ZIP file.
2. Open the science_build_lab folder.
3. Double-click index.html. It should open in your browser.
4. Try the search box, category filter, and "View build guide" buttons.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub (create an account if needed).
2. Create a NEW repository named science-build-lab.
3. Choose Public and create the repository.
4. Click Add file > Upload files. Upload index.html from this folder, then commit the changes.
5. Open the repository's Settings > Pages.
6. Under Build and deployment, choose "Deploy from a branch".
7. Select branch "main" and folder "/ (root)", then Save.
8. Wait a few minutes and refresh the Pages settings. Use the Visit site link when it appears.
   The URL usually looks like https://YOUR-USERNAME.github.io/science-build-lab/

IMPORTANT
- A public GitHub Pages website is visible to anyone. Do not put your address, passwords, school details, or private information in the site/repository.
- GitHub Pages serves static websites; it does not provide a private admin dashboard or a database for uploads.
- To add a project yourself, open index.html in a code editor and add another project object inside the `projects` array in the <script> section. Follow the existing examples. Then upload the updated index.html to GitHub again.
- Estimated prices are examples and can vary by location and parts.
- The example projects are educational models. Use low-voltage power only; never connect projects to wall sockets.
